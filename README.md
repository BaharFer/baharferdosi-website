## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/BaharFer/baharferdosi-website.git
cd baharferdosi-website
```

Install dependencies:

```bash
npm install
```

### Environment Variables

Create a `.env` file in the project root and add the required environment variable:

```env
YOUR_API_KEY=your_api_key_here
```

> Keep your `.env` file private and never commit API keys or other sensitive credentials to the repository.

### Development

Start the development server:

```bash
npm run dev
```

Vite will provide a local development URL in the terminal.

### Production Build

Create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
